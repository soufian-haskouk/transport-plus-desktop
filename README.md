\# Transport+ 🚍



Application de bureau développée en \*\*Java\*\* (Swing, JDBC, MySQL) pour la gestion des réservations de billets et des voyages pour une société de transport.



\## 🚀 Fonctionnalités

\- \*\*Authentification \& Inscription :\*\* Gestion des rôles (Admin et Client).

\- \*\*Espace Administrateur :\*\* Gestion des voyages, des offres spéciales, des réservations et statistiques.

\- \*\*Espace Client :\*\* Recherche de voyages, réservation de billets et suivi.

\- \*\*Interface graphique moderne :\*\* Composants personnalisés (RoundedButtons, GradientPanels).



\## 🛠️ Technologies Utilisées

\- \*\*Langage :\*\* Java

\- \*\*Interface :\*\* Java Swing / AWT

\- \*\*Base de données :\*\* MySQL (JDBC)

\- \*\*Outil de build :\*\* Eclipse IDE
